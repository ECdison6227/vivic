## 可使用的内容

- Control/Display 双窗、多画布、持久化/导入导出、单 owner、拖动/固定/自动排版、聚焦/恢复/删除/撤销；长内容增长和旧画布重叠修复。
- StepFun Coding Plan、GPT/Pi OAuth 两种决策连接，模型选择、等待反馈、取消、澄清延续；Pi 不开放编程工具。
- 多事项一次性提醒、事项/时长指代、暂停/修改/恢复/取消、跨画布到时提示与交付记录。
- 七类卡片，真实 Open-Meteo 天气、带来源搜索、明确数字表格/图表、已有数据转换、便笺展开/收起。
- 当前请求图片分析；独立 StepFun 语音、本地 Sherpaw ASR/VAD/KWS 与浏览器本地声音设置。TTS 默认关闭。
- 主题日夜时段、减少动效、字幕及失败降级。
- 固定预录短反馈；StepFun 同流词级时间戳与浏览器边界事件高亮；预录/云音频的 PCM 振幅驱动现有 Orb，数据不可用时按句/静态降级。仍默认关闭语音。
- Control「本地数据 → 清除全部本地数据」：确认后清除全部画布、提醒记录、显示/语音偏好和已下载语音模型；停止在途请求，其他窗口同步回到空画布。保留账号连接，不能撤销，需先导出所需画布。

开始测试见 [可复制输入和预期](MANUAL_TEST.md)，完整事实见 [实施现状](implementation-status.md)。

本轮新增实现：本地规则优先与可选 Kev、日期/重复/画布条件提醒、真实网页正文、固定公网 DNS 备选、输出设备选择、静音通知、已有 File ID 的 Plan 复刻，以及 WebKit 缓存/Firefox 背景丢失修正。最新单测 **1,209 通过、3 跳过**，类型/构建通过；Firefox/WebKit 专项 **16/16**；最终源码不录屏真实 **30 分 2.577 秒、24/24 检查通过**。Chromium 分次运行的事实及性能边界见 [增量验证](remaining-plan.md)。

## 已实现但仍待验收或观察

- 本人麦克风、默认「你好维维」的命中/误唤醒、设备切换、前台 5 分钟监听；本地 TTS 真实听感及设备离线可用性。
- 新增预录短反馈听感、真实 Plan 词级时间戳权限及音画同步；浏览器系统声音没有可测 PCM，保持零振幅。
- Pi 迁移的新 GPT 授权完整交互；真实物理 Safari、外接屏和最终源码不录屏的 GPU/长期基线。
- 旧 production snapshot 的主题选择器失败保留；本轮最终源码已完成另一次真实 30 分钟、不录屏的 24/24 检查。Headless rAF 仍有慢窗口，不称为物理 GPU 流畅度验收。
- Firefox 旧 BackgroundLayer 更新告警保留原记录；本轮消除驱动回调中的 React 状态更新，最新 Firefox/WebKit 专项未再观察到，原生 loss 也验证停止绘制。
- 构建仍有 Sherpaw 上游 WASM/Node 分支与包体积提示；生产文件语音 PoC 通过，不代表所有设备性能已验收。

更多 LLM/新 OAuth、日历/网页预览/更多 MCP、桌面系统功能、音乐、跨设备、会员等继续暂缓。输出设备选择和已有 File ID 的 Plan 音色复刻已实现；文件上传和真实账户/设备验收边界见剩余计划说明。
