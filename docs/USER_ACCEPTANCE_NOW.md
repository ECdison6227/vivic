# 当前体验与手动验收

2026-10-15，当前分支 `agent/next-iteration`。本轮顺序：用户先手测 → 明确告知测完 → Agent 打开新的 GPT 授权页面 → 用户完成登录 → Agent 验证实际 GPT 链路 → 再由用户开新 case 执行三项体验优化。

本文件中的操作由用户自己完成；不代表 Agent 获准操作真实画布、自动开麦或发声。音色复刻、其他本地决策模型评测、关闭浏览器后的提醒都不在这次验收内。Kev 暂不启用。

## 打开体验

1. 打开 <http://localhost:5173/control>，服务运行时不用重启。
2. 新建「手动验收」画布，点「打开 Vivic 展示窗口」，把两个窗口并排。Control 和 Display 使用同一浏览器、同一域名；不要一边 localhost、一边 127.0.0.1。
3. 先保持 TTS 关闭。规则、天气和明确数字的表格可先测，不必等待新的 GPT 登录。云语音另需 StepFun Plan 连接；GPT 登录不提供 StepFun 音频权限。
4. Chrome 与 Safari 不共享 IndexedDB。换 Safari 时在 Safari 重新建立测试画布和双窗，或用导出/导入迁移 TEST 数据。

## 第一组：文字、卡片和排版

| 编号 | 操作 / 输入原文 | 预期 |
| --- | --- | --- |
| B1 | `上海天气`，如有地点选项选择上海市 | 有明确反馈；选定后生成带真实来源的天气卡，不应思考结束后无解释。 |
| B2 | `给我创建一个表格`，收到数据提示后输入 `周一3，周二5，周三4` | 先询问数据，再生成 3、5、4 的表格，不编造数字。 |
| B3 | `30秒后提醒我喝水，45秒后提醒我休息，60秒后提醒我开会` | 三个事项齐全；Display 倒计时只有数字，TTS 关闭时到时不出声。 |
| B4 | `添加待办：整理资料；回复邮件；完成测试`；再输入 `把待办第二项标记为完成` | 一张三项待办，仅第二项完成；完成操作无需等待 LLM。 |
| B5 | `聚焦待办` → `恢复原视图` → `显示全部` | 只改变视图，内容和密度不变；所有卡片可见。 |
| B6 | 拖动一张卡并刷新；固定一张卡后输入 `重新排布` | 拖动位置保存，固定卡不被自动挪动，其他卡避开它。手动拖到重叠处可用重新排布整理。 |
| B7 | 缩窄展示窗口、切深浅主题、开关减少动效，再刷新两窗 | 无丢卡、闪白或不可恢复的空白；设置同步且保留。记录肉眼卡顿、字太小/太淡和正文裁切。 |
| B8 | 将 Display 移到外接屏，再尝试窗口缩放和刷新 | 卡片及背景保持可见，位置/状态一致；记录屏幕缩放比例和浏览器。 |

普通文字或数据测试失败时，先保留卡片和反馈，按编号记录。不要为了测试确认「清除全部本地数据」，它影响同源的所有画布。

## 第二组：真实语音（由用户选择时机）

先在 Control「本地语音」下载 ASR、VAD、KWS 三个模型，等待缓存/校验完成。语音输入选择「本地 Sherpaw ASR」，TTS 暂时关闭。

| 编号 | 操作 / 输入原文 | 预期 |
| --- | --- | --- |
| V1 | 按住「按住说话」，说 `十分钟后提醒我喝水`，松开 | 得到正确转写，先检查再发送。首次麦克风授权后按提示重新按住；不能漏开头或凭空多一条指令。 |
| V2 | 进入「本地唤醒（单次）」并点击「开启单次监听」，说 `你好维维`，停一下，再说 `添加待办：测试语音` | 只触发一次唤醒，只转写后半句；收完一段停止，需要再次手动开启。 |
| V3 | 重新开启唤醒，正常环境下观察约五分钟，不说唤醒词 | 不应误触发或创建卡片；单次监听到时停止。记录噪声来源和任何误唤醒。 |
| V4 | 监听或录音中点击取消；再试切走 Control 标签页/窗口 | 麦克风停止，不迟到提交旧录音；回到 Control 后需重新开启，不擅自恢复监听。 |
| V5 | 输出选「系统本地音色」，先把音量调到约 20%，再开启 TTS，输入 `显示全部` | 能听到一次确认，语速/音量设置生效，只有 Control 播放。系统本地音色列表为空则记录该情况。 |
| V6 | 有 StepFun Plan 连接时，输出选 Plan TTS，用「试听音色」比较音色和语速 | 播放及停止响应正常；没有权限时显示明确错误，不切换普通计费接口。没有 StepFun 连接可暂跳过此项。 |
| V7 | 播放一段较长的试听时点停止，或发送新指令 | 旧语音停止，不能随后自行复活或与新语音叠播；两个窗口不重复发声。 |
| V8 | 确认字幕已开启，观察字幕和 Orb；有 Plan 连接时再勾选「请求逐词字幕」 | 播放起止同步；有效词轴时正确高亮，无词轴时允许整句降级。暂停/结束振幅归零，减少动效时无振幅变化。系统音色没有振幅反馈也属正常；记录权限错误或错位。 |
| V9 | 使用 Plan TTS 试听时，浏览器支持则点击「选择输出设备」并选耳机；拔掉设备后重试。无 Plan 可暂跳过 | 所选设备出声，失效时明确提示并停止本次播放。系统本地音色跟随 OS 输出；浏览器不支持选择时记录为不支持，使用系统设置切换。 |

监听时 Control 必须保持前台；Display 可以并排观看，但点击别的窗口会让监听停止。这里不是后台常驻唤醒。

## 反馈和下一步

反馈例子：`V2 / Chrome / 原话：你好维维… / 现象：唤醒后只识别“测试” / 是否每次发生：3次中2次`。视觉问题附 TEST 画布截图、浏览器、窗口尺寸/屏幕缩放比例；不要发账号密码、Key、授权码或完整 OAuth 回调地址。

用户明确回复「手测完成」后，Agent 再发起已有「Continue with ChatGPT」的新授权流程并打开授权页面，由用户在自己的浏览器登录。若自动回调失败，完整回调地址仅填进 Control 的专用输入框，不贴聊天。不得仅复用 Pi 已有授权后把它记作新登录验收。

登录完成后再以独立 TEST 数据验证真实 GPT 结构化动作、澄清/取消、搜索及可用的图片能力；不得写入用户当前真实画布。结果确认后，新 case 可执行 [三项体验优化 brief](experience-iteration-brief.md)。
