# 决策模型跨机器测试包

2026-10-16，按用户要求整理给同学在其他机器上运行的决策模型测试资料。入口：[测试包说明](../scripts/decision-model/portable-benchmark/README.md)。此轮不下载模型、不调用真实模型、不接入新provider、不调整生产白名单，也不更改正在进行的用户反馈修复。

283条、69个合成语义家族；开发集231条、留出集52条，家族不交叉。JSON为机器源，CSV/Excel供查阅和填写；标准库Python脚本支持聊天式服务、薄评分适配器及原生模型JSONL导入。目标是有限候选下完整的意图/目标/参数/分流选择，不能冒充自由生成或产品端到端验收。结果栏没有预填新模型成绩。

范围：fit/restore/focus/Note密度；中文同义、口语、中英混合；提醒事项/剩余时长定位；待办完成/取消完成/高亮；暂停/继续/取消；计时、多事项、日期时区/重复/画布条件；天气/搜索/表格/图表分流；普通交流/总结；删除和撤销；否定/引用/非可信资料；歧义、失效焦点、序号越界、澄清续答与复合指令原子性。

验证命令：

```sh
python3 scripts/decision-model/portable-benchmark/run.py --check-data --split all
python3 -m unittest discover -s scripts/decision-model/portable-benchmark -p 'test_*.py' -v
```

只核验数据一致性、无答案输入、目标与概率判分、失败分母、留出隔离、回环假HTTP与报告导出；不以这些脚本自测声明任何模型准确率、速度或内存达标。收回同学的模型版本/量化/硬件/引擎、report.json、results.csv后，再按用例类别决定哪些意图有接入价值。

本次实际验证：9项脚本自测通过；将最终ZIP解压到独立临时目录后再次跑通数据检查、自测和283条无答案输入导出，ZIP完整性及其中8个资料文件的SHA-256核对通过。Excel三页完成渲染检查，填写两条结果后通过/失败计数、正确率及P95联动正确，恢复空白后再导出，保存文件的冻结行列和空结果栏检查通过。生成的ZIP/Excel位于本机被忽略的`outputs/vivic-decision-20261016/`，已通过文件交付发送用户；仓库源码不包含真实模型结果。
